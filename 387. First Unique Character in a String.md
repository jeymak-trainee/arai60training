
##  方針  
与えられたストリングに出現する各文字の出現回数を数えて出現順に記録しておく。次に、記録の中から出現回数が1となる最初の文字を探し、それを答えとして返す。

## 1回目  
最初は問題の前提通り、小文字のアルファベットだけからなる文字列のみが入力される前提でコードを書いてみる。 

```Java

class Solution {
    public int firstUniqChar(String s) {
        HashMap<Character, Integer> charFreq = new HashMap<>();
        for (char c : s.toCharArray()) {
            int current = charFreq.getOrDefault(c, 0);
            charFreq.put(c, current + 1);
        }

        for (int i = 0; i < s.length(); i++) {
            if (charFreq.get(s.charAt(i)) == 1) {
                return i;
            }
        }
        return -1;
    }
}

```


1回目のコードでHashMapをなんとなく使っていたが、ドキュメントを見ると、HashMapでは仕様として挿入順が保たれる保証はないと書いてあった。さらに調べて、キーが挿入順で並んでいるのを保証したいならLinkedHashMapを使う必要があるとわかったので、次はこれを使って書き直す。  
リンク：　　
https://docs.oracle.com/javase/jp/8/docs/api/java/util/HashMap.html  
https://docs.oracle.com/javase/8/docs/api/java/util/LinkedHashMap.html

挿入順が保証されてないにもかかわらず、このコードが通ってしまったのはちょっとびっくりした。

## 3回目  
Unicode文字は1文字に対して、1つのコードポイントという数値が割り当てられている。  
https://developer.mozilla.org/ja/docs/Glossary/Code_point  
なので、文字の個数はコードポイント単位で数えればいいと考えた。

```Java

class Solution {
    public int firstUniqChar(String s) {
        Map<Integer, Integer> charFreq = new LinkedHashMap<>();
        for (int i = 0; i < s.length();) {
            int cp = s.codePointAt(i);
            charFreq.put(cp, charFreq.getOrDefault(cp, 0) + 1);
            i += Character.charCount(cp);
        }

        for (int i = 0; i < s.length();) {
            int cp = s.codePointAt(i);
            if (charFreq.get(cp) == 1) {
                return i;
            }
            i += Character.charCount(cp);
        }
        return -1;
    }
}

```

JavaではUTF-16なので、Unicodeの中にはサロゲートペアを使用するものもある（絵文字とか）。そのため、ループを進めるときはコードポイントがいくつコードユニットを使用するのか注意しながら処理を書いた。



## LinkedHashMapの実装について考えてみる  
LinkedHashMapをJavaで実装してみる。

https://github.com/akmhmgc/arai60/pull/12  
参考にした上記の解答ではRubyでLinkedHashMap的なものを実装していた。参考にして自分でLinkedHashMap的なものを実装し、Acceptされたのが以下のコード。

```Java
class Solution {
    public int firstUniqChar(String s) {
        SimpleLinkedHashMap<Integer, Integer> charFreq = new SimpleLinkedHashMap<>();
        for (int i = 0; i < s.length();) {
            int cp = s.codePointAt(i);
            int value;
            if (charFreq.getValue(cp) == null) {
                charFreq.put(cp, 1);
            } else {
            charFreq.put(cp, charFreq.getValue(cp) + 1);
            }
            i += Character.charCount(cp);
        }

        for (int i = 0; i < s.length();) {
            int cp = s.codePointAt(i);
            if (charFreq.getValue(cp) == 1) {
                return i;
            }
            i += Character.charCount(cp);
        }
        return -1;
    }
}
class ListNode<K, V> {
    K key;
    V value;
    ListNode<K, V> prev;
    ListNode<K, V> next;

    ListNode(K key, V value) {
        this.key = key;
        this.value = value;
    }
}

class SimpleLinkedHashMap<K, V> {
    private final Map<K, ListNode<K, V>> index;
    private final ListNode<K, V> head;
    private final ListNode<K, V> tail;
    
    public SimpleLinkedHashMap() {
        index = new HashMap<>();
        head = new ListNode<>(null, null);
        tail = new ListNode<>(null, null);
        head.next = tail;
        tail.prev = head;
    }

    public void put(K key, V value) {
        ListNode<K, V> node = index.get(key);
        if (node != null) {
            node.value = value;
            return;
        }
        node = new ListNode<>(key, value);
        index.put(key, node);
        ListNode<K, V> prevnode = tail.prev;
        prevnode.next = node;
        node.next = tail;
        node.prev = prevnode;
        tail.prev = node;
    }

    public V getValue(K key) {
        if (index.get(key) == null) return null;
        return index.get(key).value;
    }

    public ListNode<K, V> getNode(K key) {
        if (index.get(key) == null) return null;
        return index.get(key);
    }

    public void remove(K key) {
        if (index.get(key) == null) return;
        ListNode<K, V> node = index.get(key);
        node.prev.next = node.next;
        node.next.prev = node.prev;
        index.remove(key);
    }
}
```

## 自分でクラスを作ってみた感想  
普段何も考えず用意されてるクラスを使っていたが、自分でちゃんと使えるものを実装しようとするととても手間がかかる。コンストラクタを呼んだときに型が推論できないとエラーが出て初めて、引数の有無に気を付けないといけないのを自覚した。また、解答のコードを修正中、`LinkedHashMap`で使ってた`getOrDefault`がないと、呼び出す側で`null`判定をしなければならずちょっと面倒だった。ほかにもいろいろあったが、自分の実装の雑さに気が付かされた。  
Rubyの`LinkedHashMap`では逆引きできるようにノードにキーを持たせていたので、こちらもそれに倣ってノードにキーを持たせるようにした。こうしておけばキーの一覧取得も（多分）容易に実装できると思う。
